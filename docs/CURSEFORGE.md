# CurseForge API key

A CurseForge API key is required to use the CurseForge integration in MineDock.

**The API key must never be shared with anyone or published.**

## Deutsch

Für die CurseForge-Funktionen in MineDock ist ein API-Schlüssel erforderlich.

**Dieser Schlüssel darf niemals geteilt, an andere Personen weitergegeben oder veröffentlicht werden.**
